# Documentation

- Add JSDoc to file-level classes and functions.
- File-level constants and other variable declarations do not need JSDoc.
- Start every JSDoc block with exactly one complete sentence on one physical
  line.
- Keep the summary sentence within the 72-character comment limit.
- When more explanation is useful, add a blank JSDoc line after the summary,
  then continue with one or more wrapped paragraphs.
- Add another blank JSDoc line before `@param`, `@returns`, and other tags.
- Document parameters, return values, thrown errors, and object properties
  when they are part of the declaration's contract.
- Keep descriptions specific to behavior and avoid merely repeating a symbol
  name.
